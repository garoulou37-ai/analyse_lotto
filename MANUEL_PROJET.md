# Manuel Projet Analyse Lotto

## Objectif
Créer un programme capable d'analyser des tirages de loto.

## Structure

Le dossier src contient le programme.

Le dossier data contient les fichiers CSV lus par le programme.

Les données viennent d'Internet et sont transformées en CSV.

## Récupération du projet

Emplacement principal :

~/analyse_lotto

Sauvegarde :

~/analyse_lotto_COMPLET_DATE.tar.gz

## Commandes utiles

Voir les fichiers :

find . -maxdepth 3 -type f

Voir l'historique :

git log --oneline

Voir les fichiers suivis :

git ls-tree -r HEAD --name-only

Créer une sauvegarde :

tar -czf sauvegarde.tar.gz analyse_lotto/
